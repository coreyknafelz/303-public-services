# ClearCase

ClearCase is a mobile-first Vue 3 prototype for checking a public benefits case, reviewing missing requirements, uploading documents, and getting help without calling an office.

Live app: https://303-public-services.vercel.app/

## Features

- Case-code entry and demo account sign-in
- Status overview with program cards, timeline, caseworker contact, and protected routes
- Requirements checklist with deadlines and upload actions
- Camera-first image/PDF upload flow with client-side compression, quality feedback, progress, retry, and confirmation
- English and Spanish translations, structured for adding more locales
- Persistent bottom navigation for Status, Checklist, and Help on authenticated routes
- Visible keyboard focus states and accessible core workflow controls
- Low-bandwidth mode that defers non-essential content
- PWA assets generated by `vite-plugin-pwa`

## Stack

- Vue 3 with `<script setup>`
- Vite 8
- Vue Router 4
- Pinia 4
- vue-i18n 9
- vite-plugin-pwa / Workbox
- CSS custom properties and scoped component styles

## Local development

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The demo case code is `NNW-482931`.

Useful commands:

```bash
npm run build      # production build
npm run preview    # preview the production build
```

## Deployment

The project is configured as a root-level Vite app for Vercel. `vercel.json` rewrites direct SPA routes back to `/`, so routes such as `/status`, `/checklist`, and `/help` work on refresh.

```bash
npx vercel --prod
```

The production deployment is aliased to `https://303-public-services.vercel.app/`.

## Project structure

```text
src/
	components/       reusable UI, charts, upload, status, and confirmation pieces
	composables/      upload, quality, bandwidth, and locale behavior
	data/             Rosa's demo case fixture
	locales/          independent en.json and es.json bundles
	router/           routes and case-auth navigation guard
	stores/           case, upload, and UI state
	views/            entry, status, checklist, upload, confirmation, and help screens
```

## Demo flow

1. Enter `NNW-482931`.
2. Open the checklist from Status.
3. Upload a document from the checklist.
4. Confirm the upload and optionally enable SMS updates.
5. Use the language toggle or persistent bottom navigation to move between core screens.

## Notes

This is a fictional prototype. Case data, authentication, upload processing, SMS opt-in, and callback submission are simulated locally; no real benefits system or personal data is connected.
